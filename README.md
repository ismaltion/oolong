# Oolong
An attempt at learning how to develop an operating system from scratch. NOT a usable operating system. The system will refer to itself as "oolongOS".

Although it had some previous 3 iterations, this aims to be the last one with a really strict rule: NO AI-GENERATED CODE ANYWHERE. I am not allowed to use AI for anything except asking theoretical questions. But it is absolutely prohibited for code. Even for reviews. To ensure I don't break this rule in a moment of laziness, I made this GitHub repository, so the AI code is publicily visible to anyone passing by. This should hopefully encourage me to write things myself.

## Contributing
I honestly wouldn't understand why would anyone contribute to this, after all this project was just made for my own learning, but, if you do, please explain whatever you did ig and also follow the same no AI rule. Only the Assembly and C programming languages are allowed.

## Issues
Feel free to create issues about anything, even feature requests. Just make them realistic.
